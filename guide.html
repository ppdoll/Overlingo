Overlingo 앱 열기

사용 방법

화면의 채팅창이나 영화 자막 영역을 지정하면, 그 안의 글자를 읽어 실시간으로 번역해요. 화면은 내 PC와 브라우저 안에서만 처리되고, 번역도 무료로 쓸 수 있어요.

웹에서 바로 쓰기 설치 없이 Chrome·Edge에서. 무료 내장 번역을 쓰고, 번역은 항상 위에 뜨는 작은 창(PiP)에 나와요. 데스크톱 앱 Windows용. 번역이 원래 말풍선과 자막 바로 옆에 떠요. 무료 Gemini 키로 번역해요.

웹에서 쓰기

  1. 모드와 언어 고르기

    채팅은 새로 올라온 메시지만, 자막은 자막이 바뀔 때마다 번역해요.

    원문 언어는 자동 감지로 두면 돼요. 환경 확인에서 지원 여부를 볼 수 있어요.

    화면을 공유하기 전에 샘플 화면으로 체험으로 먼저 써 볼 수 있어요.

  2. 화면 공유하고 영역 지정하기

    화면 공유 시작을 누르고 번역할 창을 고르세요. 전체 화면보다 창을 고르면 창을 옮기거나 크기를 바꿔도 영역이 따라가요.

    미리보기에서 채팅이나 자막 부분을 드래그하면, 아래에 읽힌 글자가 보여요. 잘 읽히면 번역 시작을 누르세요.

  3. 번역 보기

    번역은 다른 창 위에 항상 떠 있는 PiP 창에 나와요. 채팅은 두 가지로 볼 수 있어요.

    • 나란히: 원본 말풍선 옆에 번역
    • 목록: 번역만 메신저처럼

    그룹 채팅에서 말풍선 맨 위의 보낸 사람 이름은 번역하지 않고 따로 표시해요.

    메인 탭에는 번역 기록과 속도, 비용이 보여요.

  4. 번역 엔진 고르기 (선택)

    기본은 Chrome 내장 번역이에요. 무료이고, 언어마다 처음 한 번 모델을 받으면 오프라인으로도 돼요.

    더 자연스러운 번역이 필요하면 설정 → 내 API 키에 키를 등록하고 모드별 엔진을 바꾸세요.

    • Gemini: 무료. Google AI Studio에서 카드 없이 발급
    • Claude: 사용한 만큼 아주 적게 과금. 슬랭이 많은 채팅도 자연스러워요

    키는 이 브라우저에만 저장되고, 번역할 때 해당 회사(Google, Anthropic)로만 전송돼요.

데스크톱 앱: 말풍선 옆에 바로 번역

Windows 데스크톱 앱은 브라우저와 달리 다른 앱 위에 그릴 수 있어서, 번역을 원래 말풍선과 자막 바로 옆에 띄워요. 번역할 창을 지정하면 그 창을 옮기거나 크기를 바꿔도 따라가요. 번역 표시는 클릭이 통과돼서 채팅을 그대로 쓸 수 있고, 화면 캡처에는 찍히지 않아요.

  1. 설치하고 Gemini 키 등록

    GitHub Releases에서 설치 파일(…-setup.exe)을 받아 실행하세요. 코드 서명 전이라 Windows가 경고를 띄우면 추가 정보 → 실행을 누르세요.

    데스크톱 앱은 Chrome 내장 번역을 쓸 수 없어요. 앱의 설정 → 내 API 키에 Gemini 키를 등록하세요. Google AI Studio에서 카드 없이 무료로 발급돼요. Claude 키도 쓸 수 있어요.

  2. 번역할 창 지정

    화면 영역 지정을 누르면 화면이 잠시 멈춰요. 마우스를 올리면 창이 강조되는데, 클릭하면 그 창 전체를, 창 안에서 드래그하면 채팅창이나 자막 부분만 지정해요. 취소는 Esc예요.

    지정한 부분이 미리보기로 보이고, 아래에 읽힌 글자가 나와요. 잘 읽히면 번역 시작을 누르세요.

    메신저 없이 써 보려면 샘플 채팅 창으로 체험을 누르세요.

  3. 번역 시작

    받은 메시지는 말풍선 오른쪽에, 내가 보낸 메시지는 왼쪽에 번역이 떠요. 자막은 자막 줄 바로 아래에 나와요.

    채팅을 스크롤하는 동안에는 번역이 잠시 흐려졌다가 새 위치로 옮겨 가요. 그룹 채팅의 보낸 사람 이름은 번역하지 않아요.

    지정한 창이 최소화되거나 다른 창에 가려지면 번역을 잠시 멈추고, 다시 보이면 이어서 번역해요. 창을 닫으면 번역도 끝나요.

알아두면 좋은 점

  • 웹 버전은 Chrome·Edge 데스크톱에서 동작해요. 무료 내장 번역은 Chrome 138 이상이 필요해요.
  • 영역은 글자에 딱 맞게 지정할수록 잘 읽혀요. 글자가 아주 작으면 인식이 틀릴 수 있어요.
  • 넷플릭스 같은 DRM 영상은 캡처하면 검은 화면이라 번역할 수 없어요.
  • 화면은 내 PC 안에서만 처리돼요. Gemini나 Claude로 번역할 때만 읽은 글자가 Google이나 Anthropic으로 전송돼요.
  • Gemini 무료 등급은 보낸 글을 Google이 제품 개선에 쓰고 사람이 검토할 수도 있어요. 민감한 대화는 웹 버전의 Chrome 내장 번역(PC 안에서만 처리)이나 Claude를 쓰세요.
